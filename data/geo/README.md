# Límites departamentales simplificados

`peru_departamentos_inei2007_simplificado.geojson` es una copia sin modificar de
[`peru_departamental_simple.geojson`](https://github.com/juaneladio/peru-geojson/blob/3213eeb1bbe537f88dead45a2aadaa276fa9451d/peru_departamental_simple.geojson)
en el repositorio de Juan Eladio, commit `3213eeb1bbe537f88dead45a2aadaa276fa9451d`.
El repositorio declara licencia Mozilla Public License 2.0; copia: `LICENCIA-MPL-2.0.txt`.
Según su documentación la fuente es **INEI 2007**, distribuida por el Geoservidor del MINAM / GEOIDEP.

Son geometrías simplificadas, antiguas y pueden diferir de límites oficiales vigentes, particularmente
cerca de las fronteras. No usarlas como prueba legal ni para delimitar jurisdicción operativa.
El filtro clasifica por coordenadas de cada foco y luego agrupa celdas-día; una celda de la frontera
puede contener detecciones de ambos departamentos. La selección de la web no cambia la zona que el
bot de Telegram usa para sus avisos.
